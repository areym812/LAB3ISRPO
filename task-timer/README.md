# Task Timer

Простое расширение для Visual Studio Code: таймер рабочих сессий, перерывы, настройки и статистика.

## Возможности

- Запуск, пауза и сброс таймера.
- Режимы «Работа» и «Перерыв».
- Настройка длительности работы, перерыва и дневной цели.
- Настраиваемые уведомления и звуковой сигнал.
- График минут работы за последние семь дней.
- История завершённых рабочих сессий.
- Сохранение настроек и истории в хранилище расширения VS Code.

## Запуск в режиме разработки

1. Установите Node.js LTS и Visual Studio Code.
2. Откройте папку проекта в VS Code.
3. Откройте раздел Run and Debug.
4. Создайте конфигурацию запуска типа **VS Code Extension**, если VS Code предложит её.
5. Нажмите F5. Откроется новое окно Extension Development Host.
6. В новом окне откройте Command Palette (`Cmd+Shift+P` на macOS или `Ctrl+Shift+P` на Windows/Linux).
7. Выполните команду `Task Timer: Open`.

## Проверка синтаксиса

```bash
npm run check
```

## Структура

- `package.json` — описание расширения и команда запуска.
- `extension.js` — связь с VS Code и сохранение данных.
- `media/app.js` — логика таймера, настроек и статистики.
- `media/style.css` — оформление интерфейса.

## Ограничения первой версии

В статистику попадают только завершённые рабочие сессии. Если таймер сбросить до завершения, такая сессия не учитывается. В первой версии нет автоматического учёта времени по каждому файлу или проекту.
